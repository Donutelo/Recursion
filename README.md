# Recursion

Implementações em JavaScript de algoritmos clássicos relacionados à recursão: **Merge Sort** e a sequência de **Fibonacci**.

## Sobre o projeto

Este projeto reúne exercícios de prática com recursão. O Merge Sort ordena uma coleção dividindo-a em partes menores e combinando os resultados; a implementação de Fibonacci calcula termos da sequência usando chamadas recursivas.

## Tecnologias

- JavaScript
- Node.js
- Jest — para testes
